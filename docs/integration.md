# 최신 RoutineSlim 서버 연결 — 프론트엔드만 변경

서버 기준: 마지막으로 첨부된 `RoutineSlim-Server-dev.zip`.
서버 Java, YAML, Gradle, SQL 파일은 변경하지 않습니다. 기존 서버를 그대로 실행하세요.

## 실행

1. 이 프로젝트의 실행 중인 Vite 터미널을 Ctrl+C로 종료합니다.
2. 프론트엔드 루트의 `start-dev.bat` 또는 `scripts/start-dev.bat` 실행.
3. http://localhost:5173 접속 후 다시 로그인합니다.

의존성이 설치되어 있으면 재설치하지 않습니다. 잠긴 esbuild.exe를 매번 삭제하던 npm ci 실행을 분리했습니다.
의존성을 다시 설치해야 할 때는 프로젝트 개발 서버를 종료한 뒤 `scripts/install-deps.bat`을 실행하세요.
설치 실패 시 개발 서버를 이어서 실행하지 않습니다. 다른 프로젝트의 Node 프로세스를 자동 종료하지 않습니다.

## 환경 변수

`.env.local`은 기존 값을 유지하며, 필요한 경우 아래처럼 설정합니다.

```dotenv
VITE_API_MODE=server-dev
VITE_API_BASE_URL=
API_PROXY_TARGET=http://localhost:8080
VITE_SERVER_CATEGORY_IDS={}
```

Vite 프록시는 `/api`, `/auth`, `/users`, `/payment`, `/usage`를 서버에 전달합니다.
백엔드에 파일을 복사하지 않고 별도 포트로 실행합니다. `original` 모드는 기존 쿠키/CSRF 서버 전용이며 현재 첨부 서버에는 사용하지 않습니다.

## 실제 연결

| 기능               | 최신 서버 API                                              |
| ------------------ | ---------------------------------------------------------- |
| 회원가입·로그인    | POST /auth/signup, /auth/login                             |
| 로그인 복원        | GET /users/me                                              |
| 프로필·탈퇴        | /users/getMyInfo, /users/updateMyInfo, /users/withdrawUser |
| 월 예산·알림 일수  | PUT /users/monthly-budget, /users/notification-settings    |
| 구독 CRUD·상태·OCR | /api/v1/subscriptions 및 하위 경로                         |
| 구독 사용량        | GET /usage, PUT /usage/{subscriptionId}                    |
| 월별 실제 청구     | GET /payment/monthly?yearMonth=YYYY-MM                     |
| 구독별 최근 청구   | GET /payment/subscription/{id}?limit=24                    |

회원 API에는 로그인 UUID를 `X-Member-Id`로 보냅니다. 비밀번호는 브라우저 저장소에 저장하지 않습니다.
존재하지 않는 `/api/web/*` 경로는 요청하지 않습니다.

## 화면 계산과 저장

- 절약 검토: ACTIVE 구독의 RARELY/NEVER 사용량을 검토 상태로 표시합니다. 검토 표시 시 RARELY, 해제 시 OFTEN을 서버에 저장합니다. 해지나 일시정지 상태를 바꾸지 않습니다.
- 사용량 조회에 실패해도 정상 조회한 구독 목록은 표시하고, 검토 상태를 확인할 수 없다고 안내합니다.
- 메모는 기존 구독의 memo 필드를 사용하며, 수정 시 카드·프리셋·알림 값을 보존합니다.
- 월 예상 지출은 구독의 monthlyAmount를 사용합니다. 월간 결산과 실제 지출 차트는 청구 API의 당시 금액을 사용합니다.
- 캘린더는 시작일·주기·간격·결제일을 기반으로 계산한 예상 일정입니다. 월말과 윤년을 보정하며 PAUSED/CANCELED는 제외합니다. 실제 청구 기록을 임의 생성하지 않습니다.
- 구독 상세 결제 합계는 최근 최대 24건의 합계입니다. 전체 누적 지출로 표시하지 않습니다.
- 무료체험은 기존 구독 API의 TRIAL/CANCELED 상태 및 trialEndDate로 연결합니다.

## 카테고리

최신 서버에 카테고리 목록 API가 없어 서버 V2 기본 데이터의 ID 매핑을 사용합니다:
1 OTT/영상, 2 음악, 3 클라우드, 4 쇼핑.
기존 DB의 ID가 다르면 프론트 `.env.local`의 VITE_SERVER_CATEGORY_IDS에 실제 매핑을 넣고 Vite를 재시작하세요.
예: `VITE_SERVER_CATEGORY_IDS={"영상":4,"음악":7}`. 비어 있지 않은 매핑은 기본 매핑 전체를 대체합니다.
모르는 ID는 `카테고리 N`으로 표시하며 기존 항목 수정 시 ID를 유지합니다. 카테고리를 서버에 임의 생성하지 않습니다.

## 서버가 제공하지 않는 기능

커뮤니티·외부 요금 카탈로그·OAuth 코드 교환·이메일 인증·비밀번호 변경·변경 이력·구독 백업 일괄 복원은 현재 서버에 대응 API가 없습니다.
해당 기능은 가짜 데이터나 성공 응답을 만들지 않고 미지원 안내를 표시합니다.
실제 결제 추가·수정·삭제는 API가 없어 숨깁니다. 프로필 생년월일·주소·사진 입력은 비활성화합니다.

## 검증

`npm test`, `npm run build`, `npm run check:structure`.
최신 서버 DTO와 경로에 맞춘 프론트 계약 테스트를 포함합니다. 사용자 PC의 실행 중인 서버/DB에는 접근하지 않았습니다.

## 브라우저 전용 기능

새 페이지 없이 기존 절약 목표·알림센터·구독 비교·회원정보 화면에 추가했습니다.

- 월별 목표, 실천 체크, 절약 내역: 회원별 브라우저 저장소에 저장합니다. 목표 삭제 시 해당 내역도 삭제됩니다.
- 구독 비교: 실제 구독 목록에서 최대 3개를 선택해 비교합니다. 외부 제공업체의 최신 상품 데이터가 아닙니다. 선택은 브라우저에 저장합니다.
- 알림센터: 서버의 구독·무료체험·예산 데이터로 현재 알림을 계산합니다. 읽음·삭제 상태는 브라우저에 저장하며 푸시·문자를 발송하지 않습니다.
- 회원정보 하단 데이터 관리: 실제 구독 CSV와 선택 월 청구 CSV를 내보냅니다.
- 회원정보 하단 백업·복원: 목표·체크·절약 기록·비교 선택·알림 확인 상태만 JSON 파일로 옮깁니다. 서버 구독/결제 데이터와 비밀번호는 포함하지 않습니다.
- 복원은 같은 계정의 파일만 허용합니다. 파일을 먼저 검사하고 기록 수와 덮어쓰기 안내를 보여준 다음 사용자가 적용합니다. 잘못된 파일은 기존 데이터를 변경하지 않습니다.
- 자동 기기 동기화는 제공하지 않습니다. 시크릿 창 종료나 사이트 데이터 삭제 시 브라우저 기록이 사라질 수 있으므로 JSON 백업을 보관하세요.
- 손상된 저장소를 빈 데이터로 자동 초기화하지 않으며, 저장 공간 부족 시 저장 실패를 표시합니다.

검증: 프론트 테스트 132개, 프로덕션 빌드, 구조 검사 통과. 샘플 API 응답으로 브라우저에서 목표 생성·체크 상태 유지·JSON 다운로드/검사/복원·비교 선택을 확인했습니다. 실제 사용자 서버/DB 연결 검증과는 별개입니다.
