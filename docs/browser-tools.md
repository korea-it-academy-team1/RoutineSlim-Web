# 프론트엔드 추가 기능

이번 변경은 새 서버 API나 DB 마이그레이션을 요구하지 않습니다. 기존 API에서 읽은 데이터를 브라우저에서 계산·내보냅니다.

## 맞춤 절약 분석 → 직접 고르는 절약 시뮬레이터

- 화면 아래에서 구독 체크박스를 선택하고 3·6·12개월 기간을 고릅니다.
- 예상 월 절감액·누적 절감액·남는 월 비용·월별 누적 그래프를 확인할 수 있습니다.
- 전체 선택·초기화와 선택 항목 CSV 내보내기를 지원합니다.
- 기존 절약 검토 항목은 처음에 선택되지만 시뮬레이터 선택은 구독 상태를 바꾸지 않습니다. 선택은 화면 이동 시 초기화됩니다.
- 서버 월 환산액을 우선 사용합니다. 정지·해지 항목은 계산에서 제외하고 삭제된 선택과 중복 ID도 무시합니다.
- 비용이 즉시 중단된다는 가정이며, 실제 청구·연간 선납 환불·위약금·실제 절약 기록과는 다릅니다.

## 캘린더 → 캘린더 파일 내보내기 (.ics)

- 선택한 달 전체 일정을 Google·Apple·Outlook에서 가져올 수 있는 표준 ICS 파일로 다운로드합니다.
- 날짜 선택으로 목록을 좁혀도 파일은 해당 월 전체를 포함합니다.
- 종일 일정으로 출력하여 시간대 때문에 결제일이 전날/다음날로 바뀌지 않도록 했습니다.
- 윤년·연말·한국어·긴 문자열·구분 문자·줄바꿈 처리와 안정적인 일정 ID를 구현했습니다.
- 일회성 파일 내보내기이며 이후 서버 변경이 외부 캘린더로 자동 동기화되지 않습니다. 외부 캘린더의 중복 가져오기 정책은 서비스마다 다릅니다.
- 조회 실패·로딩·일정 없음 상태에서는 내보내기가 비활성화됩니다.

## 구독 비교

- 서비스·요금제·제공 조건 검색, 카테고리 필터와 월 환산 금액/이름 정렬을 추가했습니다.
- 주간 결제 연 52회와 결제 간격을 반영하여 월·연 환산을 계산합니다. 월 환산은 원 단위로 반올림하므로 실제 결제 합계와 다를 수 있습니다.
- 선택한 요금제 중 월 환산 최저 요금과 최대 가격 차이를 표시합니다. 요금 외 제공 조건도 함께 비교해야 합니다.
- 선택 초기화와 비교표 CSV 내보내기를 지원합니다. 비교 선택 저장 버튼의 기존 계정 저장 기능은 유지됩니다.
- 서버 목록에서 사라진 선택 ID를 제거해 비교 슬롯이 막히지 않도록 했습니다.
- 수정일 없는 요금제에서 화면이 멈추던 문제를 수정하고 누락된 가격은 무료로 간주하지 않습니다.

CSV는 한국어 Excel용 BOM을 포함하며 서비스명 등 수식으로 시작하는 텍스트를 실행하지 않도록 이스케이프합니다. 파일은 브라우저에서 생성하며 서버로 업로드하지 않습니다.

## 적용과 검증

실행·적용 방법과 현재 폴더 구조는 [README.md](../README.md)를 참고하세요. 기존 API를 사용하며 새 서버 변경 없이 작동합니다.

프론트 정리 후 중복 및 구형 구현 전용 테스트를 제외한 115개 테스트를 유지합니다. 원래 203개라는 수치는 동일 기능의 복제 테스트를 포함했습니다. 빌드와 실제 브라우저에서 시뮬레이터·비교·CSV·ICS 다운로드·모바일 화면을 확인했습니다.
