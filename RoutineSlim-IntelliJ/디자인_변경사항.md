# 스크린샷 기반 디자인 개편

- `frontend/src/components/Layout.jsx`: 루틴슬림 한글 로고, 보라색 심볼, 아이콘 메뉴, 상단 브레드크럼, 프로모션 카드, 프로필 버튼으로 변경
- `frontend/src/style.css`: 밝은 흰색/연보라 배경, 보라색 버튼, 카드/표/입력폼, 반응형 레이아웃으로 전체 화면 스타일 통일
- 기존 React 페이지 컴포넌트, API 엔드포인트, 상태 관리, Spring Boot 구조는 변경하지 않음
- 기존 '지출 차트', '월 예산', '결제 알림 설정' 메뉴는 유지하며 MY TOOLS 및 설정에 배치
- 외부 이미지 및 폰트 다운로드 없이 실행 가능하도록 SVG 아이콘을 컴포넌트에 내장
