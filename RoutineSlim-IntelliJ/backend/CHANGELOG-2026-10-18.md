- 시작 클래스 `GudokFitApplication` → `RoutineSlimApplication`
- 커뮤니티 글쓰기, 지출 리포트 UI 유지
- 글쓰기 5,000자 초과 입력 저장 차단
- IntelliJ 실행 안내 및 README 실행 클래스 수정
- `.gitignore` 추가
