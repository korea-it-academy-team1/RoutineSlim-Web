# 구독 자동 선택 및 맞춤 절감 솔루션

- 기존 디자인과 메뉴는 유지하면서 맞춤 절감 페이지를 좌측 요약/추천 목록과 우측 지출 분석/시뮬레이션/팁 카드로 재구성했습니다.
- 고정비 추가 화면의 서비스 빠른 선택 메뉴에서 넷플릭스, 유튜브 프리미엄, 스포티파이 등 17개 서비스를 선택하면 이름과 카테고리가 자동 입력됩니다.
- 서비스별 표시는 외부에서 로고를 무단 수집하지 않고 자체 문자/기호 배지로 구현했습니다. 공식 로고 파일은 포함되지 않습니다.
- 실제 등록한 구독만 집계합니다. 중복 카테고리는 탐색용 힌트이며 실제 서비스 중복이나 사용 빈도를 뜻하지 않습니다.
- 절약 검토로 표시한 구독의 월 환산 금액을 절약 시뮬레이션에 반영합니다. 실제 절약 금액이나 해지 처리를 보장하지 않습니다.
- Gmail 자동 탐지 및 카드/은행 자동 수집은 구현되지 않았습니다. 이 기능에는 사용자 동의, 외부 인증 설정, API 승인 등이 필요합니다.
- JavaScript 구문 검사 통과. Maven 빌드 및 브라우저 통합 테스트는 미수행.
