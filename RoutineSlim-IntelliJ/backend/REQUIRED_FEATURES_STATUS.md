# 필수 기능 보강 내역

- 결제 예정 알림: `/api/v1/reminders`에서 로그인 사용자의 구독만 조회해 7일 이내 결제를 반환하며, 대시보드에 표시합니다. 푸시·문자·이메일 발송은 구현되지 않았습니다.
- 실제 결제/예상 지출 구분: 기존 결제 내역 API·화면 및 구독 예측 기능 유지.
- 절감 추천: 기존 맞춤 절감 솔루션 유지. 실제 사용량을 자동 분석하지는 않습니다.
- 계정/데이터 보호: 기존 CSRF·인증·회원탈퇴 처리 유지. 회원 탈퇴 시 신고 데이터도 정리합니다.
- 커뮤니티 운영: 게시글 신고 등록, 중복 신고 차단, 관리자 신고 목록 및 처리 API 추가. 관리자는 `ROUTINESLIM_ADMIN_ID` 환경 변수 또는 `routineslim.admin-id` 속성으로 지정합니다. 신고 처리 API는 게시글을 자동 삭제하지 않습니다.

## 검사 범위
JavaScript 문법 검사, ZIP 무결성 검사를 수행했습니다. Maven 및 실제 브라우저 통합 테스트는 이 환경에서 실행하지 못했습니다. 외부 소셜 OAuth도 별도 자격 증명 및 실환경 검증이 필요합니다.
