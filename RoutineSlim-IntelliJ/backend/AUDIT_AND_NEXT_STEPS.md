# RoutineSlim 소스 점검 및 보완 기록 (2026-10-18)

## 실제 수정
- 구독 JSON 조회에서 `billingAnchorDate`가 누락되어 다음 저장 시 결제 기준일이 초기화되던 문제 수정.
- 기존 클라이언트가 결제 기준일을 보내지 않는 경우 기존 JPA 값을 보존하도록 수정.
- 프로필 JSON 용량 한도 1,500,000자 설정이 전체 1,000,000자 제한에 막히던 문제 수정.
- 유효성 검사 실패/잘못된 JSON 요청에 대해 400 응답 처리 추가.
- 로그아웃 및 회원 탈퇴 API 실패를 성공으로 표시하던 프런트엔드 오류 처리 수정.
- 기존 CSS 및 HTML 디자인 변경 없음.

## 검사 범위
- 최신 제공 ZIP의 147개 항목을 기준으로 파일 목록/주요 Controller·Service·Repository 및 인증 설정을 정적 검토.
- `node --check src/main/resources/static/js/app.js` 통과.
- ZIP 무결성 검사 통과.
- Maven 실행 파일과 프로젝트 Maven Wrapper가 없어 **컴파일·JUnit·Spring Boot 기동 검증은 하지 못함**.
- OAuth 앱 등록 정보가 없어 실제 Google/Kakao/Naver 로그인 검증은 하지 못함.
- 실제 브라우저 수동 테스트는 하지 못함.

## 남은 위험 및 개선 우선순위
1. **필수**: `mvn clean test` 및 `mvn spring-boot:run` 실행, 로그인/구독/결제/커뮤니티/탈퇴 전체 흐름 확인.
2. **필수**: H2 -> MySQL 전환 시 마이그레이션 스크립트(Flyway)와 백업·복구 체계 도입. 현재 `ddl-auto=update`는 운영용으로 부적합.
3. **필수**: 구독 JSON 호환 API를 점진 폐지하고 화면을 `/api/v1/subscriptions`로 전환. 현재 양쪽 쓰기 경로가 남아 있음.
4. **필수**: 커뮤니티 목록 페이징, 게시글/댓글 출력 DTO, 댓글 삭제·신고·관리자 조치 기능. 게시글 공개 범위/개인정보 정책 결정.
5. **필수**: 결제 예정 알림 및 실패·중복 결제 방지, 구독 해지일/무료 체험 종료일 관리.
6. **권장**: 실제 결제와 예정 금액을 구분한 월별 대시보드 및 지출 분석.
7. **권장**: 프로필 이미지 별도 파일 스토리지 사용(현재 Base64 JSON), 주소검색 실제 연동.
8. **배포 전 필수**: HTTPS 및 `SESSION_COOKIE_SECURE=true`, OAuth 공급자별 실제 로그인/콜백 테스트, CSRF/권한/입력검증 통합 테스트.

이 파일은 완료 인증서가 아니라 **실제 확인한 범위와 미검증 항목을 명시한 점검 기록**입니다.
