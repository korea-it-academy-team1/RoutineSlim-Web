# RoutineSlim 점검 결과

## 수행한 검사
- 최신 수정본 ZIP 압축 해제 및 파일 구조 확인
- 프론트엔드 JavaScript 구문 검사 (`node --check`): 통과
- 주요 API와 화면 코드 정적 검토
- 수정 ZIP 무결성 검사

## 수정 사항
- 커뮤니티 저장 실패가 성공으로 처리되던 예외 삼킴 수정
- 구독 등록·수정에서 서버 저장 성공 이후 성공 메시지를 표시하도록 개선
- 캘린더 날짜 키의 UTC 변환에 따른 날짜 밀림 가능성 수정
- 중복 상태 대입 정리
- 로그인 요청의 누락된 ID/비밀번호에 대한 입력 검증 추가
- 커뮤니티 타인 게시글의 제목·내용·태그·이미지·작성자 등 무단 변경 방지 강화
- 타인 게시글의 좋아요·댓글 변경 범위 검증 강화

## 아직 실제 검증하지 못한 항목
- Maven 빌드 및 Spring Boot 서버 실행 (현재 검사 환경에 Maven/의존성 캐시 없음)
- H2 연결, 회원가입/로그인, 구독 CRUD, 지출 그래프, 캘린더, 댓글·좋아요, 회원탈퇴의 브라우저 E2E 테스트
- Google·카카오·네이버 OAuth 실제 인증 (외부 인증키 필요)

## 배포 전 보안 과제
- Spring Security CSRF 보호가 현재 비활성화되어 있어 외부 공개 전 개선 필요
- 커뮤니티 전체 JSON 문서 저장 구조는 동시 편집 충돌과 확장성 문제가 있어 게시글·댓글·좋아요 테이블/API 분리 권장
- H2 데이터 파일과 OAuth 인증키는 GitHub에 업로드하지 말 것
