# 실행 오류 수정 내역

## 확인된 원인
첨부 로그의 SQLState 42001은 H2가 `subscriptions.day`를 SQL 식별자로 파싱하지 못해 발생합니다. 구독 조회를 공유하는 API(구독 목록, 알림, 절약 분석 등)에서 같은 예외가 반복되었습니다.

## 변경
- `backend/src/main/java/kr/routineslim/subscription/entity/Subscription.java`: `day` 필드의 DB 컬럼을 `billing_day`로 매핑. Java/JSON API 필드명 `day`는 변경하지 않음.
- `backend/src/test/java/kr/routineslim/integration/DataIntegrationTest.java`: 저장 후 구독 조회 및 결제일 값 확인 회귀 테스트 추가.

## 기존 DB 주의
Hibernate `ddl-auto=update`가 새 `billing_day` 컬럼을 생성할 수 있으나 기존 `day` 데이터가 이미 저장된 DB에서는 자동으로 값이 이전되지 않습니다. 데이터가 있는 DB는 백업 후 별도 데이터 마이그레이션이 필요합니다. **기존 H2 data 폴더를 삭제하지 마세요.**

## 검증 한계
첨부 로그의 서로 다른 ERROR 원인은 SQL 예약어 충돌 한 가지로 확인되었습니다. ZIP 및 코드 변경을 검사했지만, 이 실행 환경에서 Maven 빌드와 IntelliJ 실행은 검증하지 못했습니다.
