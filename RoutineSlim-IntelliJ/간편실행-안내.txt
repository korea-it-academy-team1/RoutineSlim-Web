RoutineSlim 한 번에 실행하기 (Windows)

1. ZIP을 원하는 폴더에 압축 해제합니다.
2. Java 17 이상과 Node.js LTS가 설치되어 있는지 확인합니다.
3. '실행.bat'을 더블클릭합니다.
4. 첫 실행은 Maven/React 패키지를 다운로드하므로 인터넷이 필요하고 시간이 걸립니다.
5. Spring Boot와 React 실행 창이 열리고 브라우저에서 http://localhost:5173/ 이 열립니다.

주의:
- 8080, 5173 포트가 다른 프로그램에 사용 중이면 충돌할 수 있습니다.
- 개발용 실행 방식입니다. 배포용 단일 실행 파일은 아닙니다.
- Google/Kakao/Naver OAuth는 별도 앱 키 설정이 필요합니다.
- 실행 창을 닫으면 서버가 종료됩니다.
- 시작 오류가 있으면 두 콘솔 창의 오류 메시지를 확인하세요.
