# RoutineSlim 전체 점검 및 수정 보고서

## 적용된 수정
- 결제 예정 알림에서 검토 중(review) 구독 제외: 실제 활성(active) 구독만 표시
- 지출 통계에서 검토 중 구독 제외: 합계/카테고리/건수의 기준 통일
- 구독 수정 시 기존 결제 기준일 유지하도록 기존 로직 보존
- 구독 요청의 주기 변경 시 기준일이 없는 경우에도 입력을 허용 (기존 프론트와 호환)
- 패키지 구조 이동 후 불필요한 자기 자신 import 제거
- 기존 H2 예약어 day 회피용 billing_day 매핑 유지

## 점검 범위 및 한계
- Java 소스 패키지/import 및 파일 경로 정적 점검
- React 페이지/API 참조 정적 점검
- Maven, JUnit, Spring Boot 구동, 브라우저 E2E는 실제 실행 성공을 확인하지 못함
- Google/Kakao/Naver OAuth는 실제 인증정보로 검증하지 않음
- 기존 H2 DB의 컬럼 이전은 자동으로 보장하지 않음
