# 추가 기능 (React)

- 마이페이지: 기존 `/api/v1/members/me` 조회·수정 API 연결
- 지출 차트: 구독 데이터 기반 월 환산 카테고리 막대 차트
- 결제 알림 설정: 0/1/3/7일 표시 기준, 사용자별 브라우저 저장
- 대시보드 알림 표시 기준 연결

## 제한사항
- 알림은 화면 표시용이며 외부 메시지를 발송하지 않습니다. 서버는 7일 이내 항목만 조회합니다.
- 구독 해지 상태는 현재 `review` 상태로 검토할 수 있지만 실제 서비스 해지 API는 제공하지 않습니다.
- React 마이페이지의 비밀번호 변경 및 탈퇴는 기존 화면에서 처리합니다.
- 전체 Maven/React 빌드 및 브라우저 통합 테스트는 별도 확인이 필요합니다.
